Hi, I'm Praveen Kumar Gopalakrishnan 👋
Senior Technical Architect | Security Architecture | Digital
Identity | Connected-Vehicle Telematics | Enterprise Integration

I work on the architecture of secure, resilient, and interoperable
systems across digital identity, connected-vehicle telemetry, and
enterprise integration. My interests include translating security and
reliability requirements into practical architectures, reference
implementations, and reproducible technical research.

Areas of Focus
- Secure Digital Identity: ISO/IEC 18013-5 mobile driver's
  licenses (mDL), cryptographic trust, selective disclosure, PKI, and
  identity verification.
- Security Architecture: Cryptographic protocols, key management,
  hardware-backed trust, threat modeling, and privacy-aware system
  design.
- Connected-Vehicle Telematics: Multi-source sensor data, temporal
  alignment, coordinate-frame uncertainty, telemetry quality, and
  evidence provenance.
- Enterprise Integration: API-led architecture, MuleSoft, cloud
  and hybrid integration, and resilient distributed systems.
- Emerging Architectures: Agentic systems, capability-oriented
  design, orchestration, and secure tool integration.
Research & Engineering Interests
I am particularly interested in building systems whose design decisions
and results can be inspected, tested, and reproduced. Topics I explore
include:
- Reliable processing of telemetry from heterogeneous sensors.
- Cryptographic provenance and integrity for connected-vehicle data.
- Privacy-preserving and relay-resilient mobile identity presentation.
- Reproducible evaluation methods, security testing, and architecture
  trade-offs.
- Secure integration patterns for distributed and agentic systems.

Approach
My engineering approach emphasizes:
- Clear architecture boundaries and explicit trust assumptions.
- Security and reliability as design properties, not afterthoughts.
- Measurable evaluation with documented methods and limitations.
- Reproducible experiments, automated tests, and maintainable
  documentation.
- Accurate attribution and respect for standards, licenses, and
  intellectual property.
